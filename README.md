## 入门指南

欢迎来到VS Code Java世界。以下是一份指南，可帮助您在Visual Studio Code中开始编写Java代码。  

## 文件夹结构

默认情况下，工作区包含两个文件夹，其中:

- `src`: 存放源代码的文件夹
- `lib`: 用于维护依赖的文件夹

同时，默认情况下，编译后的输出文件将生成在`bin`文件夹中。

> 如果您想自定义文件夹结构，请打开`.scode/settings.json`并更新其中的相关设置。

## 依赖管理

`JAVA PROJECTS` 视图允许您管理依赖项。更多详细信息请访问[此处](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).
